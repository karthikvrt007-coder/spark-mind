# Spark Mind

Daily brain games that get a little harder as you improve. Earn points. Spend them on rewards that are teasing, sexual, and written to make you open the app again tomorrow.

## Play

Open the live page (GitHub Pages) or just open `index.html` locally.

- Play any of the four mini-games.
- Score depends on accuracy, speed, and your current streak.
- Points persist in the browser (`localStorage`).
- The shop unlocks short scenes and next-day hooks. Nothing is sent to a server.

## Enable GitHub Pages

1. Repo Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root
4. Save. Site will be at `https://karthikvrt007-coder.github.io/spark-mind/`

## Games

| Game | What it trains |
|------|----------------|
| Digit span | Working memory |
| Quick math | Processing speed |
| Pattern grid | Visual memory |
| Color word | Attention / inhibition |

Difficulty ticks up with your lifetime high score in that game.

Adult content is text-only and behind a points gate. 18+ implied.
